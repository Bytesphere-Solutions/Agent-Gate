# Contributing to Agent-Gate

First off, thank you for considering contributing to Agent-Gate! It's people like you that make Agent-Gate such a great tool for secure AI-driven development.

## How Can I Contribute?

### Reporting Bugs
This section guides you through submitting a bug report for Agent-Gate.
- Make sure you are on the latest version.
- Describe the bug clearly, including the steps to reproduce it.
- Include logs from the terminal if possible.

### Suggesting Enhancements
This section guides you through submitting an enhancement suggestion.
- Provide a clear description of the new feature.
- Explain why this enhancement would be useful to most Agent-Gate users.

### Pull Requests
- Fill in the required template.
- Do not include issue numbers in the PR title.
- Make sure your code passes the build (`npm run build`) and follows the styling guidelines.

## Development Setup

1. Fork the repo and clone it to your local machine.
2. Run `npm install` to install all dependencies.
3. Run `npm run build` to compile the TypeScript files.
4. Test the CLI locally using `npm start`.

Thank you for your contributions!
